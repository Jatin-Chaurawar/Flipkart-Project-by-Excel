# 📊 Flipkart Product Data Analysis – Excel Project

Welcome to my data analytics project based on smartphone listings from **Flipkart**. This project explores patterns in pricing, brand performance, customer ratings, and discount trends using Excel's powerful analytical features.

---

## 📁 Project Overview

This project utilizes a dataset of smartphones scraped from Flipkart and organized in Excel. Through detailed analysis, we derive actionable insights using:

- **KPI dashboards**
- **Statistical formulas**
- **Pivot tables**
- **Data visualizations (charts and slicers)**

The goal is to understand how factors like pricing, brand, and reviews influence customer decisions in the online smartphone market.

---

## 📌 Key Insights

- 📈 **Average Rating:** 4.27  
- 🛒 **Average No. of Ratings:** ~47,000  
- 🗣️ **Average No. of Reviews:** ~3,400  
- 🔖 **Average Discount:** ₹4,381  
- 🏷️ **Total Brands Analyzed:** 29

## 📊 Dashboard Highlights

- **Brand vs Ratings**: Apple consistently leads in customer satisfaction.
- **Price Segmentation**: ₹20K–₹40K products balance affordability and quality.
- **Discount Impact**: Higher discounts often correlate with mid-tier ratings.
